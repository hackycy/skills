# Agent Note 指令

把这里当作“决策治理”，不要当作开发日志。

新建 Note 前先阅读 `README.md`，并搜索活跃 Note 中与当前决策、机制、所有权边界或被拒替代方案相关的记录。明确新 Note 是独立补充、缩小旧决策范围、部分替代还是完全替代，再开始写。

Agent Note 只维护一个 `.md` 文件，默认正文使用简体中文，不创建英文 counterpart、`.zh.md` 或 `.i18n.yaml`。

不要编辑 archived Note。不要借治理模板同步去修改真实决策记录。一个 implemented 决策如果被反转，应创建新的 superseding Note 并建立交叉链接，而不是把历史 Note 改写成相反结论。
