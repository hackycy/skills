# 去模板化整理

识别并移除让界面显得由 AI 套模板生成的特征：平坦层级、缺少焦点、单调布局、怯弱色板、泛化 token、默认字体和缺失状态。这是快速、局部、保持行为不变的整理，不是完整重设计。

范围默认限于当前 diff 或用户指定区域。开始前读取 `.product-interface-design/system.md`；其中已确定的选择是设计决定，不是待清理问题。

## 第一遍：眯眼看渲染结果

先看真实 UI，再读 CSS。优先使用浏览器、截图或内联渲染工具。按影响从高到低处理：

1. **没有焦点**：所有元素同等竞争。找到用户最主要的动作或信息，通过尺寸、字重、对比或隔离让它胜出，并降级其他内容。
2. **层级平坦**：不读文字就无法区分主要、次要和元数据。使用字重与四级文字色阶，不只改变字号。
3. **布局单调**：卡片尺寸、间距和密度完全相同。按内容角色改变密度，以邻近关系分组，让不同区域有节奏。
4. **颜色怯弱或泛滥**：五种低承诺浅色平均铺开，或一个强调色涂遍全屏。保留一个有意图、约占 10% 的强调色，其余颜色服务结构。
5. **边框代替空间**：到处用线画结构。优先换成留白和轻微表面层级，只在确实需要边界时保留线。

如果焦点明确、层级可读、节奏有变化、颜色克制，最严重的套模板感已经消失，再进入代码扫描。

## 第二遍：扫描当前 diff

### Token 与颜色

- 泛化名称和内联色值改为项目已有语义 token，或从产品领域命名的原语映射。
- 多个竞争强调色收敛为一个；装饰性渐变和色块删除，或赋予状态、动作、身份含义。
- 不同色相的表面收敛到同一色相，通过亮度表达层级。

### 字体

- 已有视觉方向时，移除无理由的 system/Inter 默认选择。
- 尺寸单独承担的层级补充字重与颜色。
- 大标题适度收紧字距；动态数字使用 `tabular-nums`。

### 表面与深度

- 刺眼的实色 1px 边框改为低透明边框或轻微阴影。
- 大幅表面亮度跳变收敛为几个百分点。
- 侧栏回到画布底色，以轻微边界区分。
- 混杂的深度策略收敛为一种；嵌套圆角改为同心关系。

### 状态与动效

- 为当前范围内的交互控件补齐 hover、focus、active、disabled。
- 将 `transition: all` 改为明确属性，将 `ease-in` 或默认 easing 改为低于 300ms 的自定义 ease-out。
- 添加不低于 `scale(0.95)` 的按压反馈，常用值为 `scale(0.97)`。
- 高频键盘操作移除动画；点击区域扩展到 44×44px，最低 40×40px。
- 完全缺失的 empty、loading、error 状态属于新增功能范围，只记录并交给设计评审，不在局部整理中扩建。

### 间距与结构

- 将偏离既有 4px/8px 网格的随机值吸附到尺度上。
- 无理由的不对称 padding 改为对称。
- 移除用负 margin 抵消父 padding、逃生式 `calc()` 和绕过正常流的 absolute positioning，改用清晰布局结构。

### 重复实现

- `<div onClick>` 改为真实 `<button>` 或 `<a>`。
- 缺少键盘导航、焦点管理和 ARIA 的自制 dropdown、select、modal、tooltip 改用项目已有组件或成熟 headless primitive。
- 一次性长样式若复制已有组件，改用组件或 variant；重复长 className 提取到组件或 variant。
- 项目已有 token 时，将 `bg-white`、`border-gray-200`、`#fff` 等字面量替换为语义 token。

## 不属于套模板问题的内容

- 与意图一致且执行清楚的大胆或罕见选择；
- 有明确理由的一次性圆角、焦点边框或内容驱动的不对称间距；
- 当前 diff 之外的旧问题；
- formatter 或 linter 管理的格式；
- `.product-interface-design/system.md` 已批准的决定。

不确定某项是套路还是有意决定时，保留它并在结果中说明，不进行 churn。

## 护栏与输出

- 保持业务行为不变，只修复明确视觉问题。
- 修改必须小而聚焦。需要重建信息架构或页面结构时停止局部修改，记录为设计评审后续项。
- 遵循项目现有 Tailwind、CSS、组件和命名约定。
- 输出按类别组织的 Markdown 表格，每项包含“之前”“之后”和必要的文件/属性定位；构图修复排在最前，省略没有修改的类别。
- 结尾用一至两句话总结；若第一遍发现无法局部修复的结构问题，明确建议进入 `$product-interface-design` 的设计评审模式。
