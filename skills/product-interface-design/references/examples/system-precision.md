# 产品界面设计系统：精密后台

适用于高频处理大量记录的桌面后台、运营工具和专业数据界面。

## 产品模型

**核心使用者：** 每天处理数百条记录的专业运营人员。

**高频任务：** 扫描异常、筛选工作集、批量处理、快速打开详情。

**核心对象：** 记录 / 事件 / 任务。

**主 archetype：** Table-first，可按需进入 Master-detail。

**Primary task：** 尽快找出需要处理的记录并完成动作。

**Scanning anchors：** 身份、状态、关键数值、最近变化、负责人、更新时间。

## 数据工作流

- Search：常驻工具栏，明确搜索字段。
- Filter：2–4 个高频维度常驻，其余进入高级筛选。
- Saved views：保存常用工作集。
- Selection：支持当前页与全部结果，并明确范围。
- Batch：selection mode 替换普通 toolbar。
- Detail：默认侧栏或 split view，保留列表上下文。

## 方向

**性格：** 精密与密度

**底色：** 中性偏冷

**深度：** 仅边框 + 极轻表面差

**密度：** compact

**标志性元素：** 与领域状态直接关联的紧凑状态轨道，而不是通用彩色 badge。

## Token

### 间距

基数：4px

尺度：4, 8, 12, 16, 24, 32

### 字体

正文：13–14px

标签：11–12px / 500

高优先级数值：18–24px / 600，仅在真正需要时使用

动态数字：`tabular-nums`

### 密度

- toolbar：32px
- button/input：28–32px
- table row：32–36px
- filter chip：24–28px
- icon：14–16px，命中区可扩大

## 组件模式

### 数据表

- 身份列固定；
- 数字右对齐；
- 状态靠近身份或主判断字段；
- hover 只增强定位，不承担唯一动作入口；
- selected 行使用轻微表面色而不是厚边框；
- 表头 sticky（数据量和页面高度需要时）。

### Selection toolbar

- 明确显示选中数量；
- 常规 toolbar 被批量操作替换；
- 危险动作分离；
- 支持退出选择模式。

### 详情

- 高频快速检查使用 drawer / split view；
- 复杂工作切 full page；
- 返回后保留 filter、sort、scroll。

## 决策

| 决策 | 理由 | 日期 |
|---|---|---|
| Table-first | 核心任务是扫描与处理，而不是消费汇总指标 | 2026-09-29 |
| Compact density | 用户高频鼠标/键盘操作，屏幕信息密度直接影响吞吐 | 2026-09-29 |
| Split/drawer detail | 降低处理每条记录时的上下文恢复成本 | 2026-09-29 |
