# 产品界面设计系统：精密与密度

适用于仪表盘、后台和高频专业工具的示例。

## 方向

**性格：** 精密与密度

**底色：** 冷色（slate）

**深度：** 仅边框

**核心使用者与任务：** 高频处理大量记录的专业人员，需要快速扫描、比较和操作。

**标志性元素：** 与领域状态直接关联的紧凑数据轨道。

## Token

### 间距

基数：4px

尺度：4, 8, 12, 16, 24, 32

### 颜色

```css
--foreground: slate-900;
--secondary: slate-600;
--muted: slate-400;
--faint: slate-200;
--border: rgba(0, 0, 0, 0.08);
--accent: blue-600;
```

### 圆角

尺度：4px, 6px, 8px（锐利、技术性）

### 字体

字体：system-ui（快速、原生）

字级：11, 12, 13, 14（正文）, 16, 18

字重：400, 500, 600

等宽字体：SF Mono, Consolas（数据）

## 模式

### 按钮

- 高度：32px（紧凑）
- 内边距：8px 12px
- 圆角：4px
- 字体：13px / 500
- 边框：1px，使用低透明 token

### 卡片

- 边框：0.5px，使用 faint token
- 内边距：12px
- 圆角：6px
- 无阴影

### 表格单元格

- 内边距：8px 12px
- 字体：13px，`tabular-nums`
- 下边框：1px，使用 faint token

## 决策

| 决策 | 理由 | 日期 |
|---|---|---|
| 仅边框深度 | 信息密度比抬升感更重要，阴影会增加无信息价值的视觉重量 | 2026-01-15 |
| 紧凑尺寸 | 面向高频操作的专业使用者 | 2026-01-15 |
| 系统字体 | 优先加载性能和原生感 | 2026-01-15 |
