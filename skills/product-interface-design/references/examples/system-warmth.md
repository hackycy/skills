# 产品界面设计系统：温暖与亲和

适用于协作型、内部工具或低压力工作流，但仍保留任务与状态结构。

## 产品模型

**核心使用者：** 非专业用户在低压力环境中协作、记录和完成聚焦任务。

**主 archetype：** Object workspace / Settings / 轻量 Queue。

**Primary task：** 清楚知道当前对象状态和下一步，不被复杂控制淹没。

## 方向

**性格：** 温暖与亲和

**底色：** 暖色 stone

**深度：** 轻微阴影

**密度：** comfortable

**标志性元素：** 像共享便笺一样组织的协作状态，但不牺牲状态可读性。

## Token

### 间距

基数：4px

尺度：8, 12, 16, 24, 32, 48

### 字体

正文：15–16px

辅助：13–14px

字重：400 / 500 / 600

### 控件

- button/input：40px
- card padding：20px
- section gap：24–32px

## 状态

协作状态使用文字 + 图标 + 轻语义色，不能只靠颜色。空白状态强调下一步动作，不使用无关插画填空间。
