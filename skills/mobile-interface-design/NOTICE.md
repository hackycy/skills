# References and inspiration

This skill is an original implementation informed by publicly documented ideas from:

- Anthropic's `frontend-design` Agent Skill: context-specific, subject-matter-grounded visual direction, deliberate typography/composition, and avoidance of templated defaults.
  https://github.com/anthropics/skills/tree/main/skills/frontend-design

- Google Labs Code `stitch-skills`: Agent Skill organization using `SKILL.md`, resources, examples, and scripts; and semantic design controls such as atmosphere, density, variance, motion, typography, layout, and anti-patterns.
  https://github.com/google-labs-code/stitch-skills

- `impeccable`: rendered critique, craft-floor thinking, and the use of deterministic detectors as a supplement to design reasoning rather than a replacement for it.
  https://github.com/pbakaus/impeccable

The v2 workflow also reuses and adapts original design-reasoning patterns from this repository's `product-interface-design` skill, especially domain exploration, signature elements, and anti-template review tests.

No source skill text is vendored here. The instructions, examples, resources, and validator in this package were written specifically for mobile-first H5 generation.
