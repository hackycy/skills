# References and inspiration

This skill is an original implementation informed by publicly documented ideas from:

- Anthropic's `frontend-design` Agent Skill: context-specific, distinctive frontend design and avoidance of templated defaults.
  https://github.com/anthropics/skills/tree/main/skills/frontend-design

- Google Labs Code `stitch-skills`: Agent Skill organization using `SKILL.md`, resources, examples, and scripts; and the `taste-design` concept of semantic controls such as atmosphere, density, variance, motion, typography, layout, and anti-patterns.
  https://github.com/google-labs-code/stitch-skills

No source skill text is vendored here. The instructions, examples, resources, and validator in this package were written specifically for mobile-first H5 generation.
