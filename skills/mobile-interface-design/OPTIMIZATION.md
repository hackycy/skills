# Optimization notes

Baseline: `hackycy/skills` at commit `2f25a7e7ef64747480c453fc9cd9a2ac3f700d01` (current `main` when this package was produced).

The mobile skill's last feature rewrite was `2c034be39d7fe17c68c8a8867f8c7429cd7d8a70`.

## What changed

- `single primary job` -> **dominant outcome / use mode**, allowing scan, monitor, browse, read, conversation, and compare surfaces without forcing one CTA.
- mandatory Signature Idea -> **Authored-Idea Gate**; no page-specific signature is a valid outcome.
- removed the hard `three visible manifestations` requirement.
- numeric Creativity/Density/Variance/Motion scores -> semantic **Expression / Density / Rhythm / Motion** levels with task rationale.
- named composition patterns -> structural **axes**; alternatives are generated only when structure is genuinely open.
- page-scoped -> **page-scoped by default, product-aware when context exists**.
- Domain World can affect hierarchy, terminology, grouping, state, and interaction without becoming visible theming.
- first-viewport rule changed from “primary job/CTA must be obvious” to **early viewport must earn its space**.
- examples were rewritten to demonstrate reasoning shape without repeatedly seeding the same visual solutions.
- rendered review now includes a product-continuity test.
- mobile interaction lists are explicitly examples, not feature checklists.

## Intentionally preserved

- mobile-first H5 / WebView scope;
- product-truth preservation;
- domain-grounded reasoning;
- rendered review loop;
- replacement and squint tests;
- safe-area, keyboard, touch, width-resilience rules;
- static validator and icon assets;
- existing licensing/notice material.
